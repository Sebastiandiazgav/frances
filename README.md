# Ma famille — Présentation interactive 🇫🇷

Presentación interactiva (HTML + CSS + JS) para la tarea de francés **"Ma famille"**.
Diapositivas con solo imágenes y palabras clave para hablar, no leer.

## 🚀 Demo

Desplegada en Vercel. Abre `index.html` para verla en local.

## ✨ Características

- 7 slides: portada → 4 personas → quiz → cierre
- Flip cards interactivas por cada dato
- Navegación con teclado (← →), pantalla completa (F)
- Selector de idioma FR / ES
- Quiz final interactivo con puntaje

## 📁 Estructura

```
├─ index.html   → estructura
├─ style.css    → diseño
├─ script.js    → interactividad
├─ data.js      → datos (editable)
└─ _docs/       → guion para hablar + doc extendida (no se despliega)
```

## 🛠️ Uso local

Abre `index.html` en el navegador. No requiere instalación.
